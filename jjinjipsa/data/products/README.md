더 좋은 제품이라는 뜻이 아니고, 이 목록에 없다고 나쁜 제품도 아닙니다.

### 챗봇에 그대로 쓰면 안 되는 이유

시스템 프롬프트 **R7**이 이렇게 정하고 있습니다.

- 특정 상용 제품을 "좋다/나쁘다"로 단정하지 않는다
- 제품 순위를 매기지 않는다
- "많이 먹는 것 ≠ 좋은 것"임을 안내한다
- 처방식(신장·요로 등)은 엄격히 수의사 처방 영역임을 명시한다

이 목록을 그대로 추천에 쓰면 R7과 정면으로 충돌합니다. 특히 목록에는
**처방식이 53건 섞여 있습니다** (힐스 k/d·c/d·i/d·z/d, 로얄캐닌 레날·유리너리·
가스트로, 몬지 레날 등). 질환 맥락 없이 노출하면 위험합니다 — 처방식은 진단
없이 먹여선 안 되고, 잘못 먹이면 오히려 해가 됩니다.

### 쓸 수 있을 만한 방향 (아직 미구현 · 별도 결정 필요)

1. **제품명 인식** — 집사가 "로얄캐닌 유리너리 먹여도 될까요?"라고 물을 때
   등록된 제품명임을 알아채고, 처방식이면 "수의사 처방 영역"으로 안내
2. **사료 전환 안내의 예시 어휘** — 제품 순위가 아니라 표기 확인 방법 설명에 활용
3. **입력 자동완성** — 프로필의 "현재 급여 사료" 입력 시 후보 제시

어느 쪽이든 **순위·추천으로 읽히지 않는 형태**여야 하고, 도입 전 DECISIONS.md에
기록이 필요합니다.

### 알려진 데이터 이슈

원본을 손대지 않고 그대로 보관하므로, 확인된 오기를 여기에 적어둡니다.

| 위치 | 내용 |
|---|---|
| 습식 섹션 | `미우타임즈 스탠다드` — 미우타임즈는 **모래** 브랜드이며 모래 섹션에도 있음. 분류 오기로 보임 |

그 밖에 여러 분류에 함께 등장하는 항목들(사료∩습식 23건, 습식∩간식 10건,
`페스룸`이 모래·간식 양쪽)은 **브랜드가 실제로 두 제품군을 모두 만드는 경우**라
오류가 아닙니다.

### 검증

```bash
# 항목 수·중복·분류 혼입 확인
python3 - <<'PY'
import re
src = open("data/products/고다카페_제품리스트.md", encoding="utf-8").read()
for s in re.split(r"^## ", src, flags=re.M)[1:]:
    title = s.split("\n")[0]
    items = [l[2:].strip() for l in s.split("\n") if l.startswith("- ")]
    print(f"{title:20} {len(items):4}개 | 고유 {len(set(items)):4}개")
PY
```
