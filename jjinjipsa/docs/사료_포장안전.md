## 1. 왜 포장 상태가 안전 문제인가

밀봉 캔은 내용물을 멸균 상태로 유지하는 것이 전부다. 밀봉이 깨지면 공기와 미생물이
들어가고, **산소가 없는 캔 안**은 일부 균이 자라기 좋은 환경이 된다. 그래서
포장 손상은 "모양이 상했다"가 아니라 **내용물이 상했을 수 있다**는 신호다.

고양이는 사람보다 체구가 작아, 같은 양의 독소·오염에도 영향을 더 크게 받는다.
"사람이 먹어도 될 정도면 고양이도 괜찮다"는 성립하지 않는다.

## 2. 먹이지 않는다 (폐기 권고)

| 상태 | 왜 |
|---|---|
| 캔이 부풀어 있음 (뚜껑·바닥이 볼록) | 안에서 가스가 찼다는 뜻 — 미생물이 증식 중일 수 있다. **가장 위험한 신호** |
| 뚜껑 테두리·이음매(밀봉선)가 찌그러짐·접힘 | 밀봉이 깨졌을 수 있다. 몸통보다 이 부위가 훨씬 중요하다 |
| 날카롭게 각지게 눌린 자국, 구멍, 찢어짐 | 미세한 틈으로 오염이 들어간다 |
| 새거나 젖은 자국, 끈적임 | 이미 내용물이 새고 있다 |
| 관통할 정도의 녹, 부식 | 금속이 얇아져 밀봉을 못 한다 |
| 열었을 때 "칙" 소리가 없음 | 이미 압력이 빠졌다 = 밀봉이 깨져 있었다 |
| 냄새·색·질감이 평소와 다름, 거품 | 변질의 직접 증거 |

## 3. 대체로 괜찮다 (다만 확인)

- **몸통의 얕고 매끈한 찌그러짐** — 이음매와 뚜껑이 멀쩡하면 대체로 문제없다.
  다만 열었을 때 §2의 마지막 두 줄(소리·냄새)을 확인하라고 안내한다.
- 라벨 찢어짐·구겨짐만 있는 경우 — 캔 자체가 멀쩡하면 안전과 무관하다.

## 4. 판단이 안 될 때

사진에서 이음매가 안 보이면 **추측하지 않는다.** 뚜껑 테두리가 보이는 각도로
한 장 더 요청한다. "괜찮아 보여요"를 근거 없이 말하는 것이 가장 나쁜 답이다.

## 5. 이미 먹인 뒤라면

포장 이상을 뒤늦게 알았고 이미 먹였다면, **증상이 없으면 지켜본다.**
다만 아래는 트리아지 기준표의 🔴에 해당하므로 즉시 병원이다.

- 힘이 빠져 늘어짐, 걷지 못함, 동공 이상 등 신경 증상 (`lib/redFlags.ts`의 neuro)
- 반복 구토 + 축 처짐 (vomit-lethargy)
- 24시간 이상 절식 (anorexia)

## 6. 라벨을 읽어주는 것은 '평가'가 아니다

R7은 제품에 순위를 매기거나 추천하는 것을 금지한다. 하지만 **라벨에 적힌 사실**
— 브랜드, 제품명, 종류, 원산지, 원재료, 성분 표기, 유통기한 — 을 그대로 읽어주는 것은
평가가 아니라 관찰이다. 이걸 피하면 집사는 "그래서 이게 뭔데?"만 남는다.

읽히지 않는 항목은 **"사진에서는 안 보여요"라고 말한다.** 지어내지 않는다.
