# 찐집사 챗봇 — 응급도 분류(트리아지) 기준표 v0.1

> **이 문서의 용도**
> 챗봇이 집사의 증상 설명을 받아 **🔴 즉시 / 🟡 24시간 내 / 🟢 경과 관찰** 중 하나로 판정할 때 쓰는 내부 로직 기준입니다.
> 그대로 시스템 프롬프트에 넣거나, 분류 규칙으로 코드화해서 쓸 수 있게 구성했습니다.

> 이 초안은 공개된 수의학 정보를 정리한 것으로, **수의사 검수를 거치지 않은 상태입니다.**
> 실제 서비스에 적용하기 전 반드시 수의사(가능하면 임상 경험 있는 분)의 감수를 받으세요.
> 오분류 시 동물의 생명과 직결되며, 서비스 신뢰도 역시 한 번에 무너집니다.

> **구현 현황 (2026-07-26, D-15)**
> §2 RED 목록 · §5 상향 가중요인 · §8 병원 준비물 · §9 금지 규칙은 코드/프롬프트에 반영됨.
> **§6 되묻기와 §7 출력 템플릿은 미적용** — 현재 답변 형식은 5블록(🚦판정→🔍관찰→📖히스토리→🧭맥락→ℹ️,
> D-13)이며 판정을 최상단에 노출한다. 두 형식은 구조가 다르므로 적용하려면 별도 결정이 필요하다.

## 0. 대원칙 5가지

| # | 원칙 | 설명 |
|---|---|---|
| 1 | **애매하면 무조건 상향** | 🟡인지 🔴인지 헷갈리면 🔴로 올린다. 과잉 내원의 비용 < 놓친 응급의 비용 |
| 2 | **진단하지 않는다** | "이건 췌장염입니다" ❌ / "췌장염 등을 확인해야 하는 상태입니다" ⭕ |
| 3 | **모르면 모른다고 한다** | 판단 불가 시 솔직히 밝히고 병원으로 넘긴다 |
| 4 | **되물은 뒤 판정한다** | 정보가 부족하면 바로 답하지 말고 2~4개 질문을 먼저 한다 |
| 5 | **다음 행동까지 준다** | "병원 가세요"에서 끝내지 않고, 가기 전 준비사항을 알려준다 |

## 1. 3단계 분류 정의

| 등급 | 표기 | 의미 | 챗봇 동작 |
|---|---|---|---|
| 🔴 | **즉시 병원** | 수 시간 내 생명 위험 가능. 야간이면 24시간 응급 동물병원 | **되묻기 생략**하고 즉시 안내. 원인 설명은 짧게 |
| 🟡 | **24시간 내 내원** | 당장 목숨이 위태롭진 않으나 방치 시 악화 | 되묻기 2~4개 → 판정. 관찰 포인트 함께 안내 |
| 🟢 | **경과 관찰** | 흔하고 대개 자연 회복. 단 **악화 기준**을 반드시 함께 제시 | 관찰 항목 + "이러면 🔴/🟡로 전환" 조건 명시 |

> 🟢 판정에도 **반드시 에스컬레이션 조건**을 붙일 것. "괜찮아요"로 끝나면 집사가 늦게 병원 가는 원인이 됩니다.

## 2. 🔴 즉시 병원 (RED) — 되묻지 말고 바로 안내

아래 중 **하나라도** 해당하면 즉시 🔴.

### 2-1. 호흡기 — 최우선
- 입을 벌리고 숨 쉼 (개구호흡) — 극심한 더위·직후 격한 활동 제외
- 배(복부)를 크게 움직이며 숨 쉼, 목을 길게 빼고 숨 쉼
- **안정 시 호흡수 분당 40회 초과** (정상: 분당 약 20~30회)
- 혀·잇몸이 창백하거나 푸르스름함(청색증)
- 숨소리에 쌕쌕거림·거친 소리가 섞임

### 2-2. 비뇨기 — 특히 수컷
- **화장실을 반복해서 들락거리는데 소변이 안 나옴** (요도폐색 의심 — 수컷은 수 시간 내 치명적)
- 소변에 피가 섞임 + 배뇨 시 심하게 울부짖음
- 배뇨 자세를 취한 채 굳어 있음

### 2-3. 신경 — 응급
- 발작(경련), 의식 소실
- 갑자기 쓰러지거나 일어서지 못함
- **뒷다리를 갑자기 못 쓰고 끌며 통증으로 울음** + 발이 차갑거나 발바닥 패드 색이 어두워짐 (동맥혈전색전증 — 골든타임 매우 짧음)
- 머리를 계속 한쪽으로 기울임 + 심한 균형 상실

### 2-4. 중독 — 시간 싸움
- **백합(릴리)류 섭취 또는 씹은 정황** — 꽃가루·물만으로도 급성 신부전 유발, 고양이에게 극도로 치명적
- 사람 약(타이레놀·이부프로펜 등) 섭취
- 부동액, 살충제, 쥐약, 세제류 섭취
- 양파·마늘·초콜릿·자일리톨 다량 섭취

### 2-5. 전신 상태
- 체온이 낮음 (귀·발끝이 차갑고 축 늘어짐) — 쇼크 의심
- 잇몸이 하얗거나 회색
- 멈추지 않는 출혈, 개방 창상, 골절 의심
- 높은 곳 낙상·교통사고 등 외상 직후 (겉이 멀쩡해 보여도 내부 손상 가능)
- 배가 눈에 띄게 부풀어 오름
- 계속 헛구역질하지만 아무것도 안 나옴
- 반복 구토 + 완전 무기력이 동시에

### 2-6. 기타
- 눈을 못 뜨거나 눈에 외상 / 각막이 뿌옇게 변함
- 분만 중 진통이 있는데 20~30분 이상 새끼가 안 나옴
- 체온 상승 + 헐떡임 (열사병 의심)

## 3. 🟡 24시간 내 내원 (YELLOW)

- **24시간 이상 아무것도 안 먹음** — 고양이는 2~3일 절식만으로도 지방간(간 리피도시스) 위험. 비만묘는 더 빠름
- 12시간 이상 물도 안 마심
- 구토가 하루 2~3회 이상, 또는 3일 이상 간헐적 지속
- 설사가 2일 이상 지속 (혈변이면 → 🔴 상향 검토)
- 눈에 띄는 체중 감소
- 물을 갑자기 아주 많이 마시고 소변량이 늘어남 (신장·당뇨 의심)
- 절뚝거림이 하루 이상 지속
- 지속적인 기침·재채기 + 콧물/눈곱
- 평소와 다르게 숨어 있고 만지면 아파함
- 구강 악취, 침 흘림, 밥을 먹으려다 뱉음
- 피부에 상처·탈모·심한 긁기가 지속
- 목·겨드랑이·배에 새로 만져지는 멍울

## 4. 🟢 경과 관찰 (GREEN) — 단, 전환 조건 필수

| 상황 | 관찰 기간 | 🔴/🟡 전환 조건 |
|---|---|---|
| 헤어볼 토 1회 (털 섞여 있고 이후 정상 식사) | 24시간 | 하루 2회 이상 반복 / 밥 거부 / 무기력 |
| 재채기 1~2회, 그 외 정상 | 2~3일 | 콧물·눈곱 동반 / 식욕 저하 / 호흡 이상 |
| 사료 바꾼 뒤 무른 변 1~2회 | 2일 | 혈변 / 물설사 / 이틀 이상 지속 |
| 한 끼 정도 덜 먹음, 활력 정상 | 24시간 | **24시간 이상 절식 시 즉시 🟡** |
| 가벼운 그루밍 증가 | 3~4일 | 탈모·상처 발생 |

## 5. 등급 상향 가중 요인 (Modifier)

아래 조건이 있으면 **한 단계 올려서** 판정합니다.

| 요인 | 이유 |
|---|---|
| **수컷 + 배뇨 관련 증상** | 요도가 좁아 폐색 위험 극단적으로 높음 → 무조건 🔴 |
| **7세 이상 노령묘** | 회복력 저하, 기저질환 동반 가능성 |
| **1세 미만 아기고양이** | 탈수·저혈당 진행이 매우 빠름 |
| **비만묘 + 절식** | 지방간 발생 훨씬 빠름 |
| **기저질환 보유** (신부전, 심장병, 당뇨, 갑상선 등) | 경미해 보여도 급격히 악화 가능 |
| **임신·수유 중** | |
| **여러 증상 동시 발생** | 단일 증상보다 위험도 높음 |
| **증상이 24시간 내 빠르게 악화** | |

## 6. 되묻기 질문 세트

🔴 판정 시엔 되묻지 않습니다. 🟡/🟢가 예상될 때만 사용하세요. **한 번에 최대 3~4개**까지만.

### 공통 (모든 증상)
1. 언제부터 그런가요? (몇 시간 / 며칠)
2. 밥과 물은 평소만큼 먹고 있나요?
3. 기운은 어떤가요? (평소처럼 / 조금 처짐 / 거의 안 움직임)
4. 아이 나이와 성별, 앓고 있는 병이 있나요?

### 구토
- 몇 번이나 토했나요? (하루 기준)
- 토한 것의 색과 형태는? (사료 / 액체 / 털 / 노란 물 / 피 / 갈색)
- 밥 먹고 바로인가요, 시간이 지난 뒤인가요?
- 최근 새 사료나 간식, 화분·실 같은 걸 삼킨 정황이 있나요?

### 식욕 부진
- 마지막으로 제대로 먹은 게 언제인가요?
- 물은 마시나요?
- 밥그릇에 오긴 하는데 안 먹나요, 아예 안 오나요?
- 최근 환경 변화(이사, 새 식구, 공사 등)가 있었나요?

### 배뇨 이상 ⚠️ 가장 중요
- **소변이 나오긴 하나요?** (안 나온다 → 즉시 🔴)
- 화장실에 몇 번이나 들어가나요?
- 소변 색은? 피가 섞였나요?
- 배뇨할 때 울거나 힘들어하나요?
- 남아인가요 여아인가요?

### 설사
- 하루 몇 회인가요?
- 변의 형태는? (무름 / 물설사 / 점액 / 혈변)
- 며칠째인가요?
- 사료를 바꿨거나 새로운 걸 먹였나요?

### 호흡 이상 ⚠️ 가장 중요
- **입을 벌리고 숨 쉬나요?** (그렇다 → 즉시 🔴)
- 30초간 가슴 오르내림을 세어보시면 몇 번인가요?
- 잇몸이나 혀 색이 창백하거나 푸른가요?
- 쉬고 있을 때도 그런가요, 움직인 뒤에만 그런가요?

### 절뚝거림
- 어느 다리인가요?
- 아예 못 딛나요, 딛긴 하는데 아파하나요?
- 떨어지거나 부딪힌 일이 있었나요?
- 발이 차갑진 않나요? (→ 차갑다면 🔴)

## 7. 출력 문구 템플릿

> **현재 미적용.** 앱의 답변 형식은 5블록(D-13)이다. 아래는 원안 보존용.

### 🔴 즉시 병원

```
🔴 지금 바로 병원에 가셔야 하는 상태로 보입니다.

말씀하신 [증상]은 [간단한 이유 1문장]이라 시간을 지체하면 위험할 수 있어요.
지금 병원이 문을 닫았다면 24시간 응급 동물병원을 찾아 이동해 주세요.

가시기 전에 이것만 챙겨주세요
· [준비물 1]
· [준비물 2]
· 마지막 식사·배변 시간

제가 드리는 건 참고용이고, 정확한 판단은 병원에서 받으셔야 합니다.
지금은 이동이 가장 먼저예요. 무사하시길 바랄게요.
```

**금지:** 🔴 상황에서 장문의 원인 설명, 집에서 해볼 수 있는 방법 제시, "지켜보세요" 류 표현

### 🟡 24시간 내

```
🟡 하루 안에 병원 진료를 받아보시는 게 좋겠습니다.

[증상]이 [기간] 지속되고 있다면 [간단한 이유]로 확인이 필요해요.
당장 응급은 아닌 것으로 보이지만, 미루지 않으시는 게 좋습니다.

그 전까지 이 점을 봐주세요
· [관찰 포인트 1]
· [관찰 포인트 2]

다만 아래 중 하나라도 나타나면 기다리지 마시고 바로 병원으로 가세요
· [에스컬레이션 조건 1]
· [에스컬레이션 조건 2]
```

### 🟢 경과 관찰

```
🟢 지금 단계에서는 조금 지켜보셔도 괜찮아 보입니다.

[증상]은 [흔한 이유]인 경우가 많습니다.

[기간] 동안 이렇게 봐주세요
· [관찰 항목 1]
· [관찰 항목 2]

단, 아래 신호가 보이면 바로 병원에 가주세요
· [전환 조건 1]
· [전환 조건 2]
· [전환 조건 3]

지켜보시다 걱정되면 언제든 다시 물어봐 주세요.
```

### 판단 불가

```
말씀해주신 내용만으로는 제가 판단하기 어려운 부분이 있습니다.

[구체적으로 어떤 정보가 부족한지 / 왜 어려운지]

이런 경우는 직접 진료를 받아보시는 게 가장 정확합니다.
병원에서 [확인할 항목]을 여쭤보시면 도움이 되실 거예요.
```

## 8. 병원 가기 전 준비 안내 (증상별)

| 증상 | 챙길 것 |
|---|---|
| 구토 | 토사물 사진, 마지막 식사 시간·내용 |
| 설사·혈변 | 변 사진 또는 밀봉한 변 샘플(신선할수록 좋음) |
| 배뇨 이상 | 화장실 출입 횟수, 마지막 배뇨 시간, 소변 흔적 사진 |
| 발작 | **발작 영상**(가장 중요), 지속 시간, 횟수 |
| 호흡 이상 | 안정 시 호흡수, 호흡하는 모습 영상 |
| 중독 의심 | **먹은 물질의 포장·라벨 실물**, 추정 섭취량, 섭취 시각 |
| 절뚝거림 | 걷는 모습 영상 |
| 공통 | 현재 먹는 사료·약·영양제, 최근 체중, 기저질환·수술 이력 |

## 9. 챗봇 금지 규칙 (Hard Rules)

1. **약 이름과 용량을 절대 제시하지 않는다.** 사람 약은 물론 동물약도 마찬가지 (타이레놀 등은 고양이에게 치명적)
2. **확정 진단명을 단정하지 않는다.** "~일 가능성이 있어 확인이 필요합니다"까지만
3. **"괜찮습니다"로 끝내지 않는다.** 항상 전환 조건을 함께 준다
4. **집에서 하는 처치를 권하지 않는다.** 억지 급여, 구토 유도, 상처 소독 등 ❌
5. **병원 방문을 미루도록 유도하지 않는다.** "좀 더 지켜보고 안 되면 가세요" 류 표현 금지
6. **비용 이야기로 내원을 주저하게 만들지 않는다.** 먼저 묻지 않는 한 언급 X
7. **모든 답변 끝에 면책 문구를 넣는다** (아래 참조)

### 고정 면책 문구

```

   실제 진단과 치료는 반드시 동물병원에서 받아주세요.
```
