## 2. 문제 진단

### ① 고양이 상세가 홈+기록을 통째로 복제한다 — 가장 큰 중복원

`/cats/[id]`(391줄)에 오늘 상태·건강 카드·최근 증상이 **모두** 들어 있다.
홈과 기록 탭에 있는 것과 같은 내용이다. 집사 입장에서 "이건 어디서 보는 거지?"가 된다.

### ② 냥박사 탭에 고유 화면이 없다

`/chat`은 17줄짜리 리다이렉트다. 탭을 누르면 화면 없이 고양이 챗으로 튕겨나간다.
홈에도 같은 진입점(냥박사 카드)이 있어서 **탭 하나가 자리만 차지한다.**

### ③ 지난 대화를 다시 볼 방법이 없다

`listSessions`는 챗 화면 안에서 세션을 이어붙이는 데만 쓰인다. 대화 목록 UI가 없어
**"저번에 냥박사가 뭐라고 했더라"를 확인할 수 없다.** 판정 기록은 다시 보게 될 정보인데
빠져 있다. ②와 합치면 자연스럽게 해결된다.

### ④ 탭 이름이 명사라 경계가 흐리다

"기록"과 "우리 아이"는 둘 다 명사이고, 고양이 정보는 양쪽에 다 있다.
어디로 가야 할지 이름만으로 판단되지 않는다.

## 3. 설계 원칙

1. **한 정보는 한 화면이 소유한다.** 다른 화면에서는 *요약 + 링크*만 둔다.
   요약도 원본과 형태가 달라야 한다(같은 카드를 그대로 복제하지 않는다).
2. **탭은 행동으로 가른다.** 명사가 아니라 "지금 뭘 하러 왔는가"로 나눈다.
3. **홈은 한 마리, 나머지는 전체.** 홈은 선택된 아이의 오늘을 다루고,
   기록·우리 아이는 모든 아이를 다룬다.
4. **진입점은 여러 곳에 둘 수 있다.** 중복 금지는 *정보*에 적용되고,
   *행동 버튼*에는 적용하지 않는다 (냥박사로 가는 길은 여러 개여도 좋다).

## 4. 목표 구조

| 탭 | 행동 | 소유하는 정보 |
|---|---|---|
| **홈** | 오늘 뭘 할까 | 선택 고양이의 **오늘 상태 입력**, 오늘 할 일 |
| **냥박사** | 물어보기 | **지난 상담 목록**, 새 질문 시작 |
| **기록** | 돌아보기 | **증상 기록 전체**, **건강 카드**(공유) |
| **우리 아이** | 관리하기 | **프로필**(추가·수정·삭제), 계정 설정 |

### 화면별 책임

**홈 `/`**
- 소유: 오늘 상태 입력, 냥박사 진입, 로그인 유도
- 요약만: 최근 기록 2건 → 기록 탭으로 링크 (현행 유지)
- 빼는 것: 없음

**냥박사 `/chat`** — ✅ 구현됨 (2026-07-28)
- 소유: 지난 상담 목록. 세션이 고양이당 하나씩 이어지는 구조라 세션 목록은
  고양이 목록과 다를 게 없어서, 답변에서 **🚦 판정을 뽑아 시간순으로** 보여준다
  (`lib/chatHistory.ts`). 되묻기·일반 답변은 판정이 없으므로 이력에서 제외
- 행동: 새 질문 시작, 고양이 전환
- 리다이렉트를 대체함

**기록 `/records`**
- 소유: 증상 기록 전체 목록, 건강 카드(공유 기능 포함)
- 현행 유지

**우리 아이 `/cats`**
- 소유: 고양이 목록·추가·수정 진입, 계정 설정
- 현행 유지

**고양이 상세 `/cats/[id]`** — 축소 대상
- 소유: **그 아이 고유 정보만** — 히어로(사진·이름·나이), 생애 시계,
  "꼭 기억할 것" 메모, 프로필 수정·삭제
- 빼는 것: 오늘 상태 입력(→홈), 건강 카드(→기록), 최근 증상 목록(→기록)
  대신 각각 **한 줄 요약 + 해당 탭으로 가는 링크**를 둔다

## 4-1. 네비게이션 규칙

**탭에는 뒤로가기를 두지 않는다.** 탭은 하단 네비로 전환하는 최상위 목적지라,
"돌아갈 상위 화면"이 없다. 뒤로가기는 **하위 화면에만** 둔다.

| 구분 | 화면 | 뒤로가기 |
|---|---|---|
| 탭 (최상위) | `/` `/chat` `/records` `/cats` | ❌ 없음 |
| 하위 화면 | `/cats/[id]`, `/cats/[id]/chat`, `/cats/[id]/log`, `/account` | ✅ `BackButton` |

`BackButton`은 앱 안에서 이동해 왔으면 `router.back()`으로 실제 왔던 화면으로
돌아가고, 딥링크·새로고침이면 `fallback`(논리적 상위)으로 보낸다.
그래서 **냥박사 탭 → 지난 상담 → 챗 → 뒤로가기 → 냥박사 탭**으로 정상 복귀한다.

> 냥박사 탭에 뒤로가기를 넣을지 검토했으나(2026-07-28), 기록·우리 아이 탭과
> 어긋나고 막다른 길도 없어서 현재 규칙을 유지하기로 했다.

## 5. 이행 계획

작은 것부터, 각 단계마다 배포하고 확인한다.

| 단계 | 내용 | 위험 | 상태 |
|---|---|---|---|
| 1 | **냥박사 탭에 상담 목록 화면 신설** — 없던 기능을 채운다. 기존 화면을 건드리지 않아 안전 | 낮음 | ✅ 2026-07-28 |
| 2 | **고양이 상세 축소** — 오늘 상태·건강 카드·최근 증상을 요약+링크로 교체 | 중간 (익숙한 화면이 바뀜) | |
| 3 | 탭 라벨 검토 — 필요하면 행동형으로 조정 | 낮음 | |

1단계를 먼저 하는 이유: **빠진 기능을 채우는 일**이라 순수하게 얻는 것만 있고,
2단계에서 "상세에서 뺀 것"이 갈 곳도 이때 생긴다.
