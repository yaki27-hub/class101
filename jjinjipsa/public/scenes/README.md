# 히어로 씬 일러스트

홈 히어로 상단 440px를 채우는 그림. **무드 5종 각각 1장씩, 총 5장이 필요합니다.**

## 파일

| 파일명 | 무드 | 그려야 할 것 |
|---|---|---|
| `sunny.webp` | 컨디션 최상 | 햇살 든 창가 · 기지개 |
| `cloudy.webp` | 컨디션 보통 | 같은 방, 흐린 빛 · 웅크림 |
| `warning.webp` | 관찰 필요 | 빈 물그릇 클로즈업 · 노을빛 |
| `sick.webp` | 이상 신호 | 창밖 비 · 담요에 파묻힘 |
| `night.webp` | 취침 · 야간 | 불 끈 방 · 달빛과 스탠드 |

파일명은 `lib/homeMood.ts`의 `MoodId`와 1:1로 맞습니다. 이름을 바꾸려면 거기도 같이 고쳐야 합니다.

## 규격

- **정사각 880×880 WebP.** 히어로가 390×440으로 그려지므로 2배가 880입니다.
  원본(1254² PNG, 장당 2MB대)을 그대로 넣으면 홈 첫 화면마다 몇 MB를 받게 됩니다.
- **아래 25%는 무드 색 스크림이 덮습니다.** 고양이 얼굴·핵심 오브젝트는 위쪽 70% 안에.
- **좌우 각 3% 정도 잘립니다** (`object-fit: cover`). 가장자리에 중요한 걸 두지 마세요.
- **같은 방, 같은 아이.** 시간과 상태만 바뀐 것으로 읽혀야 무드 전환이 성립합니다.
  방이 달라지면 5장이 그냥 다른 그림이 됩니다.

## 변환

```bash
npx sharp-cli -i <원본.png> -o public/scenes/<무드id>.webp resize 880 880 --fit cover
```

## 색보정은 넣지 않습니다

한때 1장을 CSS 필터(`saturate`·`sepia`·`hue-rotate`)와 무드색 소프트라이트 틴트로
5무드에 돌려 썼습니다. 무드마다 제 색을 가진 그림이 들어온 뒤로는 걷어냈습니다 —
이미 색이 맞춰진 그림에 또 씌우면 의도한 색이 망가집니다.

무드 색과 그림을 잇는 것은 스크림 하나뿐이고, 그 정지점은 `lib/homeMood.ts`의
`heroScrim()`과 `heroBg()`가 440px에서 서로 맞물려 있습니다. 한쪽만 바꾸면 이음매가 보입니다.
