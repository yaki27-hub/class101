## D-26 (2026-08-09) 홈 무드 실데이터 연결 + 오늘 상태 입력 복원 (T-53·T-51)

- **무드·점수·3칩이 이제 오늘 상태 기록(식사·물·배변·활동)에서 계산된다**
  (`computeHome`). 판정 순서는 **아픈 신호 > 시간대**: 이상 1건 → sick /
  주의 1건 또는 체중 진료 권고 → warning / 밤(21시~5시) → night /
  나머지는 점수 85 기준 sunny·cloudy. `?mood=`는 시안 더미 미리보기로만 남는다
- **점수는 의학 지표가 아니라 오늘 기록의 상태 요약**이다:
  58 + 기록×10 − 주의×14 − 이상×30 (15~99). 4항목 정상=98.
  **기록 전엔 숫자를 지어내지 않는다** — 점수 대신 "오늘 기록 전이에요"
- 입력 복원(T-51): "오늘 상태 기록하기"와 히어로 3칩 탭 → 4항목 시트.
  네 항목을 한 시트에 펼쳐 연속 기록(항목마다 여닫으면 기록이 일이 된다).
  선택 즉시 저장, 뒤의 히어로가 실시간으로 바뀌는 게 기록의 보상
- 케어 캘린더 실데이터: 민트 점 = 그날 오늘 상태 또는 증상 기록이 있음 (11일)
- 루틴 토글은 아이별·날짜별 localStorage — 자정이 지나면 자연 리셋
- **D-day 카드는 홈에서 뺐다.** 접종·재진 데이터 소스가 없는데 더미 D-7을
  보여주면 가짜 알림이다. 영수증 OCR(T-47)로 vet_visits가 생기면 붙인다
- warning·sick의 냥박사 한마디에서 "이틀 연속 음수량이…" 같은 **사실 단정
  카피를 제거** — 트리거가 무엇이든 참인 문구로 바꿨다. 무드 시스템에서
  카피가 데이터를 앞서가면 그게 곧 오보다
- 회귀: `npm run test:mood` 9건 (판정 순서·기록 전 null·unknown 제외)
