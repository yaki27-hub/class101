- 정직성 규칙 (주간 리포트와 동일 원칙): 분모는 기록한 날 / 표본 5일 미만이면 비교
  않고 "알아가는 중" / 오늘은 표본에서 제외(자기 오염 방지) / unknown 제외 /
  다름의 방향(좋아짐·나빠짐)은 단정하지 않는다 — "조금 달라요"까지만.
- 오늘 기록한 항목만 카드에 보인다 — 기록 전 항목을 "모름"으로 나열하면 잔소리가
  된다. 기록 유도는 히어로 칩과 CTA의 몫.

## D-43 (2026-08-18) 🔖 기억해둘게요 카드 — **모양은 모카, 확정은 집사**

- 대화에서 증상 이야기가 감지되면 뜨던 "기록 남길까요?" 제안을 모카 프로토타입의
  기억 카드(세이지 테두리 · 🔖 헤더+시각 · "태그 ｜ 요약" · 수정/기억하지 않기)로 교체.
- 모카 원안은 **자동 저장 + 사후 취소**지만 따르지 않았다. 태그 추출이 키워드
  기반이라 "구토하면 병원 가야 해요?" 같은 가정 질문도 잡히는데, 자동 저장하면
  가짜 기록이 냥박사 회상을 오염시킨다 — 지어낸 기록이 "지난번에도 그랬죠"가 된다.
  그래서 [기억해두기]를 눌러야 저장된다. 저장 후엔 "기억했어요" 확인 카드.
- [수정]은 카드 안에 편집기를 만들지 않고 증상 기록 화면으로 태그·메모를 프리필해
  보낸다. 응급 태그도 프리셀렉트 대상에 포함시켰고, 룰엔진 라벨("호흡 이상")처럼
  기록 화면 어휘에 없는 태그는 조용히 떨어져 집사가 정확한 칩을 직접 고른다.
- 대화발 기록도 지표에 잡는다: symptom_saved { from: "chat" }.

## D-41 (2026-08-15) 생활기록부 → **칠판 버전** (리디자인 핸드오프 A안)

- 흰 종이 카드를 버리고 **판에 분필로 직접 쓴다.** 판 위에 흰 카드를 올리면 판이
  배경 그림으로 격하되기 때문 (핸드오프 핵심 결정). 섹션 순서는 요약 먼저:
  제목(Gaegu 손글씨, 제목 한 줄만) → 오각 레이더 → 담임 의견 → 12줄 → 빈 칸 칩.
- 칠판 규칙: 보조선(눈금·스포크·점선 헤어라인)은 전부 점선 — 실선이 되면 인쇄물처럼
  보인다. 데이터 폴리곤만 실선. 등급은 잉크 5색 동그라미로, **진하기 순이 아니다**
  (D-20 유지). 담임 의견에 붉은색 금지. 배경 상단(레이더 자리)에는 아무것도 안 둔다.
- 핸드오프에 없지만 유지한 둘: **초안 제안(P2-1)** 은 칠판 톤으로 재도색하되
  `data-noncapture`로 **공유 사진에서는 뺀다**(앱 도구지 기록부 내용이 아니다).
  **정사각 카드(P2-3)** 는 저장 시트에서 "칠판 그대로"와 나란히 남긴다.
- 핸드오프와 다른 점 하나: 배경 판이 화면 고정이 아니라 콘텐츠와 함께 스크롤한다 —
  fixed 요소는 html-to-image 클론에서 위치가 깨져 "판 전체 캡처"가 불가능해서다.
- 캡처 구현 메모: 본문 컨테이너는 grid가 아니라 **flex** — grid는 클론에서 행 높이가
  굳은 채 자식(초안 박스)만 빠져 겹침이 생긴다. 실측으로 확인한 제약.
- ReportCard(흰 종이 긴 카드) 삭제. 종이 버전 스펙은 핸드오프 부록 B에 남아 있어
  되돌리는 것은 색 교체 수준이다. GRADE_STYLE(종이 배지 색)은 그래서 남겨 둔다.

## D-40 (2026-08-14) 계정 바뀜 경고 — 막지 않고 알린다

- 배경: 카카오는 브라우저에 카카오계정 세션이 남아 있으면 계정 선택 없이 그 계정으로
  바로 로그인시킨다. 실사례 — 재로그인 후 "오늘 상태 체크가 초기화"된 것처럼 보였는데,
  실은 아침 세션과 재로그인이 **다른 카카오 계정**이었다 (양쪽 다 "달이"가 등록돼 있어
  화면만으로는 구분 불가). 동기화는 양쪽 모두 정상이었다.
- 조치 ①: 설정 화면에 로그인된 카카오 이메일을 **반드시** 표시. 카카오는 u.email을
  비워 두고 identity_data로만 이메일을 주는 경우가 있어 세 곳을 순서대로 본다
  (`resolveAccountEmail` — 설정·경고가 같은 규칙을 쓴다).
- 조치 ②: 이 기기의 마지막 정식 로그인 uid를 localStorage에 기억하고, 다른 계정으로
  들어오면 토스트로 알린다 ("지난번(A)과 다른 카카오 계정 — B. 이전 기록이 안 보이면
  설정에서 확인"). **막지는 않는다** — 일부러 계정을 바꾸는 경우도 있다.
- 익명 세션은 비교하지 않는다 — 익명 uid는 기기마다 갈리는 값이라 항상 "바뀜"이 된다.
  판정은 순수 함수(`classifyAccountSwitch`)로 두고 `test:authwarn`(10건)이 고정한다.
- 브라우저 검증: A 첫 진입(무경고) → A 재진입(무경고) → B 진입(경고) → B 재진입(무경고).
